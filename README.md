## ✨ Features

StatKit provides a comprehensive collection of statistical tools for analyzing numerical datasets directly in the browser.

### 📊 Descriptive Statistics

Calculate essential statistical measures including:

- Count
- Sum
- Mean
- Median
- Mode
- Minimum
- Maximum
- Range
- Variance
- Standard Deviation

---

### 📐 Population & Sample Statistics

Choose between:

- **Population variance**
- **Sample variance**

StatKit automatically calculates the corresponding standard deviation based on the selected variance type.

---

### 🔢 Dataset Analysis

Explore your dataset with:

- Sorted values
- Unique value count
- First quartile (Q1)
- Third quartile (Q3)
- Interquartile range (IQR)

---

### 📋 Frequency Distribution

StatKit automatically calculates the frequency of every unique value in the dataset.

Example:

```text
Value      10   20   30   40
Frequency   2    3    1    2
